# Security Policy

## Supported versions

Security updates are provided for the `0.1.x` release line.

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues. Report them
privately through [GitHub private vulnerability reporting](https://github.com/devkrity/narad/security/advisories/new)
or by emailing [security@devkrity.com](mailto:security@devkrity.com).

Include the affected version or commit, the impact, and clear reproduction
steps. Please allow time for investigation and a fix before sharing details
publicly.
