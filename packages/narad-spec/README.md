# @devkrity/narad-spec

Canonical Narad protocol package: JSON Schema, conformance traces, and the `narad/v1` prose spec. Clients reduce an authority journal; they never append. This package is that journal's contract. It has no runtime code.

The TypeScript client (`@devkrity/narad`) and React bindings (`@devkrity/narad-react`) consume these traces. See the [repo README](../../README.md) for what Narad is and how to pin this package from git.
